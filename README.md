# E-Commerce Sales Analysis Dashboard

## Project Overview
This project focuses on analysing e-commerce sales data using MySQL and Power BI. It explores revenue, orders, product performance, customer segments, discounts and payment methods through SQL queries and an interactive dashboard.

## Tools Used
- MySQL – Data querying and analysis
- Power BI – Dashboard development and data visualization

## Database Tables
- `orders` – Order transactions, quantity, discount and total amount
- `customers` – Customer details, city, gender and customer segment
- `products` – Product names and categories
- `offers` – Promotional codes and offer details

## Key Performance Indicators
- Total Revenue: ₹1,93,74,915
- Total Orders: 1,204
- Average Discount: 16.15%
- Units Sold: 10,773
- Average Order Value: ₹16,092.12

## Dashboard Insights
The dashboard includes:
- Revenue by Product Category
- Top 10 Products by Revenue
- Revenue by Customer Segment and Gender
- Units Sold by Category
- Orders by Payment Method
- Revenue by Offer

It also includes Month and City slicers for interactive filtering.

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- Aggregate Functions
- GROUP BY
- INNER JOIN
- COUNT, SUM and AVG
- Filtering and sorting
- Business-oriented sales analysis

## Project Objective
To analyse e-commerce sales performance, identify top-performing products and categories, understand customer purchasing patterns, and provide useful business insights through an interactive dashboard.
